# Stand festhalten (Memory)

Nach jeder Runde einen Absatz in die Projekt-Memory-Datei schreiben (Datum, Kennungen). Wer die Sitzung später fortsetzt, soll ohne Rückfrage weiterarbeiten können.

```
## <Thema>, Runde <n> (<Datum>)
- **Auftrag / Wunsch des Auftraggebers:** …
- **Gebaut (Kennungen):** D1 …, D2 …, P1 …; Hintergründe l0 bis l7; Schalter Blau-Seite, Spot.
- **Entschieden:** D2 + P2 + l7 + Blau rechts + Spot ganz links. (oder: "noch offen: …")
- **Dateien:** Builder, Optionen-Seite, Staging-Ordner, Diff, Server (Name in launch.json, Port).
- **Geprüft:** Breiten, Überlauf, Fehler, Touch/Maus, Druck. **Nicht geprüft:** …
- **Nächster Schritt:** Freigabe zum Kopieren / Commit-Befehle / Live-Prüfung.
- **Regeln, die dabei sichtbar wurden:** (z.B. Schriftregel) → eigene Feedback-Datei.
```

Außerdem: Entscheidungen des Auftraggebers über Marke und Arbeitsweise als eigene, kurze „Feedback“-Notiz mit Begründung (Warum, Wie anwenden) ablegen, damit sie in jeder Sitzung gelten.
